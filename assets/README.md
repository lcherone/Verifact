# Verifact assets

The `brand/` vectors contain original geometric artwork authored for Verifact in this workspace. They do not incorporate third-party logos, icon paths, photographs, fonts or generated raster imagery. No additional third-party asset attribution or redistribution condition is introduced by these original files; distribute them with Verifact under the project's chosen terms.

- `verifact-mark.svg`: full evidence-aperture symbol for dark surfaces, 48-unit geometry.
- `verifact-mark-light.svg`: the same geometry with the light-theme accent.
- `verifact-mark-small.svg`: optical simplification for 16–20 px, with a solid center rather than a tiny ring.
- `verifact-app-icon.svg`: editable 1024 px application-icon source.
- `verifact-app-icon.png`: deterministic rasterization of that source for packaging and documentation.
- `Verifact.icns`: macOS multi-resolution application icon, produced from the same source.

The four registration corners suggest observation. A diamond focal plane and central sample point suggest one precise fact supported by surrounding evidence. No checkmark, robot or decorative AI motif is used. Keep the mark upright, preserve clear space of at least one eighth of its width, and do not add gradients, glow or a second outline.

For interface action glyphs, use the companion `gpui-component-assets` 0.5.1 Lucide set consistently. That dependency carries third-party icon licensing separately; these brand assets are not replacements for generic action icons. System UI and Menlo fonts are selected by name and are not bundled.
